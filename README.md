# 漫游 · AI 漫剧智能推荐系统

当前为纯前端交互 Demo，使用 12 部虚构作品演示界面和操作流程。未接入模型、向量数据库或真实推荐后端；浏览器内通过简单规则模拟偏好识别、筛选和排序。

## 本地体验

**直接体验**：双击项目根目录的 `Demo.html`，使用现代浏览器打开即可，无需启动服务、联网或安装依赖。

**开发预览**：需要 Node.js 20 或以上版本，无第三方依赖，无需安装依赖。

```powershell
cd 'D:\_长安大学\_个人简历\项目经历\AI漫剧智能推荐系统'
npm start
```

在浏览器打开 <http://127.0.0.1:4173>。终端保持运行，按 `Ctrl+C` 停止。端口被占用时，可在 PowerShell 中使用 `$env:PORT = '4174'` 后重新运行。

## 可以体验的流程

- 发现页：输入观剧需求，或选择灵感示例，查看自动识别的口味。
- 调整偏好：修改题材、剧情特色、节奏和明确排除项，再生成片单。
- 推荐结果：展示推荐理由、偏好差异和原始模拟简介，符合条件不足 3 部时不补齐。
- 示例片库：按题材浏览全部虚构作品，查看内容信息。
- 体验说明：可一键进入无匹配或生成失败场景；失败后可保留偏好重试。

输入修改后会重新识别全部偏好，不保留上一轮条件。自然语言识别仅覆盖演示关键词，不代表真实模型理解能力。

## 检查与测试

```powershell
npm run check
npm test
npm run build
```

自动测试覆盖偏好提取、否定条件、未知标签的保守处理、排序、结果数量、无匹配和冲突条件等逻辑。浏览器验收清单见 [Demo 验收记录](demo/验收记录.md)。

修改 `demo/` 下的源文件后，运行 `npm run build` 重新生成单文件 `Demo.html`。请勿直接修改生成文件。

## 目录

- `demo/`：页面、样式、原创 SVG 插画、模拟数据和前端规则；`server.mjs` 仅提供静态文件。
- `tests/`：使用 Node.js 内置测试运行器执行的逻辑测试。
- `产品设计文档.md`：MVP 范围与后续方向。

所有作品名称、简介、集数和封面均为演示创作；没有真实播放链接，也没有用户行为、模型效果或满意度数据。
