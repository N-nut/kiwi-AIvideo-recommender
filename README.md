# 奇维 Kiwi · AI 漫剧智能推荐系统

品牌采用猕猴桃切面与播放三角组合的原创 SVG Logo，页面强调色为清新绿色。

当前为纯前端交互 Demo，使用 12 部虚构作品演示界面和操作流程。未接入模型、向量数据库或真实推荐后端；浏览器内通过简单规则模拟偏好识别、筛选和排序。

## 本地体验

**直接体验**：双击项目根目录的 `Demo.html`，使用现代浏览器打开即可，无需启动服务、联网或安装依赖。

**开发预览**：需要 Node.js 20 或以上版本，无第三方依赖，无需安装依赖。

```powershell
cd 'D:\_长安大学\_个人简历\项目经历\AI漫剧智能推荐系统'
npm start
```

在浏览器打开 <http://127.0.0.1:4173>。终端保持运行，按 `Ctrl+C` 停止。端口被占用时，可在 PowerShell 中使用 `$env:PORT = '4174'` 后重新运行。

## 可以体验的流程

- 发现页：输入观剧需求，或选择灵感示例，查看自动识别的口味。
- 调整偏好：修改题材、剧情特色、节奏和明确排除项，再生成片单。
- 推荐结果：展示推荐理由、偏好差异和原始模拟简介，符合条件不足 3 部时不补齐。
- 示例片库：按题材浏览全部虚构作品，查看内容信息。
- 卡片预览：鼠标悬停约 260ms 展开详情，自动循环播放静音模拟片段；移出后收起。支持暂停、Esc 关闭，手机可点击展开。
- 个人收藏：使用演示昵称登录，在展开卡片中加入或取消收藏，通过「我的收藏」查看；同一昵称可恢复本机收藏。
- 体验说明：可一键进入无匹配或生成失败场景；失败后可保留偏好重试。

输入修改后会重新识别全部偏好，不保留上一轮条件。自然语言识别仅覆盖演示关键词，不代表真实模型理解能力。

登录与收藏仅通过浏览器 `localStorage` 模拟，无真实身份认证、密码、服务器或跨设备同步。不同昵称的收藏分开保存；退出不删除收藏。存储不可用时降级为当前页面暂存。双击文件与静态服务属于不同浏览环境，收藏不保证互通。

预览包含五段原创 6 秒 WebM 氛围动画，由项目的 SVG 插画录制，按题材复用，非真实漫剧素材。单文件内嵌视频，可离线体验；浏览器禁止自动播放时显示播放按钮，减少动态效果模式下默认不自动播放。需要支持 Popover API、WebM 的现代浏览器。

## 检查与测试

```powershell
npm run check
npm test
npm run build
```

自动测试覆盖推荐逻辑、登录与收藏状态、账号隔离、存储异常、悬停延迟与取消、浮层边界、视频分段读取和单文件打包。浏览器验收清单见 [Demo 验收记录](demo/验收记录.md)。

修改 `demo/` 下的源文件后，运行 `npm run build` 重新生成单文件 `Demo.html`。请勿直接修改生成文件。

## 目录

- `demo/`：页面、样式、原创 SVG 插画、模拟数据和前端规则；`server.mjs` 仅提供静态文件。
- `demo/assets/`：五段原创静音 WebM；`demo/preview-studio.html` 为录制工具，可通过静态服务打开并生成素材。
- `tests/`：使用 Node.js 内置测试运行器执行的逻辑测试。
- `产品设计文档.md`：MVP 范围与后续方向。

所有作品名称、简介、集数、封面和预览均为演示创作；没有真实剧集播放链接，也没有真实用户行为、模型效果或满意度数据。
