# 媒体预览操作说明

正式页面对全部 AI剧、漫剧和真人剧使用同一真实预览组件，默认有声并支持静音切换。服务启动补齐既有作品，更新短剧库成功后自动为新增作品准备首集前 15 秒；漫画预览框仅显示“漫画暂不支持预览”，不显示画面。视频不随 Git 分发，新环境按实际任务结果显示准备中、就绪或不可用。独立 `Demo.html` 保持模拟演示。

## 自动准备

在项目根目录安装 Python 依赖及 `npm ci`。配置 `FFMPEG_PATH / FFPROBE_PATH` 为已有工具路径；Windows 默认使用已安装 Edge，Linux 设置 `PREVIEW_BROWSER_CHANNEL=chromium` 并运行 `npx playwright install --with-deps chromium`。Compose 后端镜像包含这些运行时，但镜像与部署尚待本机实测。

默认配置为 `PREVIEW_AUTO_ENABLED=true`、`PREVIEW_WORKERS=2`（上限 3）、`PREVIEW_ATTEMPTS=3`、`PREVIEW_RETRY_SECONDS=60`、`PREVIEW_FETCH_TIMEOUT=60`。Node 不在 PATH 时设置 `PREVIEW_NODE_PATH`；Playwright 不在项目依赖目录时设置 `PREVIEW_PLAYWRIGHT_MODULE`。不用 Python Playwright。

正常启动产品即可后台补齐，资料更新完成不等待所有视频生成。侧栏显示就绪数和处理状态；当前浮层显示“预览准备中”，保持打开时就绪后自动播放。失败不会删除作品或使用其他剧集冒充，更新短剧库后会重新尝试，已有有效片段复用。也可在停止产品后独立运行：

```powershell
.\.venv\Scripts\python.exe -m kiwi sync-previews --retry-failed
```

任务持久化到数据库，重启恢复中断；该命令等候全部任务结束，有不可用作品或服务错误时返回退出码 1。工具或浏览器不可用会报告服务错误；修复后重启或重新更新。自动解析只接受已入库红果作品的公开首集，并核对作品 ID、完整标题和首集 ID。已确认来源 404 的记录保持当前不可用状态，来源标识或链接改变后再处理。

若源站更名而作品 ID 未变，自动进一步核对公开详情页，确认源站现名和首集一致后，同步标题、简介、封面、标签、集数及可获取的榜单信息，更新索引并继续生成预览；原 ID 和收藏关联保留。ID 或首集不符、资料不完整时不覆盖旧资料。实际同步结果见 [源站同步验证](source-sync-validation.json)。无法正常打开或实际下载失败的来源如实保留不可用状态；媒体用于本机开发验证，公开访问不等于来源方授予对外传播许可。

实际覆盖、编码和文件完整性检查见 [片库媒体检查](preview-library-validation.json)，新作品真实自动准备见 [自动验证](auto-preview-validation.json)。原先 3 部样本的处理记录见 [导入验证](preview-import-validation.json)。

## 配置与准备

在项目根目录运行命令。安装带 `libx264`、AAC 编码器的 FFmpeg 和 ffprobe，在 `.env` 设置 `FFMPEG_PATH`、`FFPROBE_PATH`（命令名或完整可执行文件路径）。`MEDIA_ROOT` 默认 `.local/media/previews/`，`MEDIA_DELIVERY_MODE=app`。`ffmpeg -version`、`ffprobe -version` 与 `ffmpeg -encoders` 可核对工具；本机使用已有 EVCapture 配套工具，实测版本写入导入报告。

先停止服务和导入，再运行 `python scripts/prepare-previews.py`：脚本使用 SQLite backup API 同步备份数据库和媒体目录，并恢复到独立目录检查完整性、既有数据指纹与每段视频 SHA-256，最后新增本地表。备份保存在 `.local/backups/previews-<时间与随机标识>/`，不删除旧文件。新环境执行 `python -m kiwi init`；PostgreSQL 执行 `alembic -c backend/alembic.ini upgrade head`，媒体表迁移为 `0004`，持久准备队列为 `0005`。不可将空库初始化替代已有数据备份。

## 准备清单与导入

复制 [清单示例](../data/preview-manifest.example.json) 到 `.local/preview-manifest.json`，每部一条，填已有作品 ID、本地普通视频文件、公开来源页、使用依据、选段与两项确认。相对源路径基于清单目录。没有核实作品对应或本次用途依据时保留确认值为 `false`，只会登记 `pending`。CLI 不下载远程视频；文件不超过 200 MB、选段 10～20 秒且不越过源文件结尾。

```powershell
.\.venv\Scripts\python.exe -m kiwi import-previews --manifest .local/preview-manifest.json --check-only
.\.venv\Scripts\python.exe -m kiwi import-previews --manifest .local/preview-manifest.json
```

命令输出 JSON：`ready / pending / skipped / failed` 及逐部阶段；有失败时退出码为 1。检查模式不发布或写库。正式导入会裁切、转码、生成封面并检查实测输出，再发布随机版本文件并切换当前记录；失败保留旧片段。重复相同输入跳过。`.previews.import.lock` 使用操作系统锁，进程退出自动释放所有权，文件本身可以保留；`preview-orphans.jsonl` 记录事务失败的未引用版本，不自动删除旧媒体。

本机 3 部样本由用户指定从红果公开第一集截取开头 15 秒，记录本地开发使用依据；来源方对外传播许可未据此确认，独立人工内容复核仍待完成。

## 验证与部署

启动产品后，在片库搜索上述作品并点击“预览”。默认有声，底部“打开声音／静音”按钮只切换声音，不调节音量；暂停后继续保留当前声音选择，切卡、重试或重新打开时恢复有声。确认声音切换、暂停、来源详情、Esc、关闭后媒体卸载以及缺素材／失效重试。浏览器自动检查使用已安装的 Playwright 与 Edge：

```powershell
node scripts/verify-real-previews.mjs
node scripts/verify-card-preview.mjs
.\.venv\Scripts\python.exe -X utf8 scripts/verify-auto-previews.py
```

浏览器验证的 Playwright 不在默认路径时设置 `KIWI_PLAYWRIGHT_MODULE`。两个 Node 脚本复制公共作品及媒体元数据到独立测试库，不复制业务账号；自动准备关闭，读取既有媒体文件；默认使用 8002 和 8001，结束自动停止临时服务。真实视频脚本要求已有至少 3 部 `ready` 素材；布局脚本专门检查无媒体时的布局，不代替真实播放。Python 自动验证以一条既有公开作品元数据作为采集夹具，在空库中执行一次更新，实际访问来源并生成新文件，再验证重复更新复用；不修改业务库。来源临时失败会使该在线验证失败，可在网络恢复后重试。

Compose 新增 `kiwi-media` 卷：后端 `/media/previews` 读写，Nginx 同路径只读，媒体入口仍由 API 校验。默认应用直出。只有内部 location、卷文件和权限验证通过后才设置 `MEDIA_DELIVERY_MODE=nginx`；外部直接请求 `/_kiwi_previews/` 应返回 404，并验证 200／206／416、HEAD、撤回及旧版本拦截。当前本机未完成容器与 Nginx 实测。

备份时停止媒体导入，在同一时间点保存数据库与整个媒体卷；恢复到独立目录并核对当前记录和文件、完整读取／Range 后再切回。降级或回滚数据库不删除媒体；恢复匹配的两份备份后才能重新启用服务。
