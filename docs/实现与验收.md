# 奇维 MVP 实现与验收

更新日期：2026-10-22。

## 本轮交付

- 移除原 36 部 Bilibili 种子，默认作品文件改为空；已有 SQLite 原位升级并只移除指定旧作品 ID。原本机数据库已备份至 `.local/kiwi-before-hongguo-20261022.db`。
- 首页右上角按钮改为“更新漫剧库”。点击后后台采集、校验、建立索引、原子更新片库；页面显示阶段进度与最近成功时间，结束后自动加载新卡片。
- 固定采集用户指定的 [真人剧分类首页](https://hongguoduanju.com/category/real-drama) 和 [红果热播榜首页](https://hongguoduanju.com/rank/hot-drama)。当前范围为两页当前展示的作品，不遍历分页。
- 兼容页面直接 JSON 和两种流式加载 JSON；不执行来源脚本、不访问私有接口、不下载视频。超时、页面大小、重试次数、单页作品数量均有限制；不跟随任意重定向。
- 按来源 series_id 去重，保留真实标题、封面、简介、标签、来源、集数及排名/热度。来源未说明的作品类型显示“未标注”，真人剧不会统一标成漫剧。
- 运行中重复点击复用任务；任务状态持久化，页面刷新后继续查看；结束后 30 秒内复用最近结果。重启会标记未完成任务为中断，可重新发起。
- 两个来源及所有作品均成功处理后才替换红果片单；失败保留原库及其他手工导入作品。仅热度、日期、封面等元数据变化时复用已有向量。
- 无模型密钥也能采集和浏览；缺少向量配置时保留未就绪状态，不声称已具备真实语义检索。配置后再次更新可补齐索引。
- 保留偏好解析、编辑确认、硬条件筛选与语义推荐、来源详情、本机收藏、悬停模拟视频、长详情正文滚动及空白处关闭。

## 真实链路验收

浏览器实际点击“更新漫剧库”，2026-10-22 本次结果为分类页 **24 条**、热播榜 **20 条**，按作品标识去重后 **41 部**。真实调用百炼 text-embedding-v4（1024 维）后，`/health/ready` 返回 `live / ready`，资料 **41 条**、有效向量 **41 条**。

页面自动从空片库变为 41 部。首屏展示与红果榜单对应的作品名称、封面和前三名热度；浏览器确认三张图片均加载成功，没有水平溢出。详情包含原始资料、来源分类、榜单、采集日期、未知特征和待人工复核标记，官方链接指向对应 series_id。
